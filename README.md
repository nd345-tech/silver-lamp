
This is a Terraria mod for my CSC 375 (Open-source Development) class in my Junior year. This mod was made in C# with TmodLoader as the medium. This mod aims to add some things into the game to make it more fun for players without changing core gameplay too much. This mod adds a variety of features including:
- new weapons for the melee, ranged, and magic classes
- a new boss fight
- new ore
- new armor
- a new accessory

To play and run this mod you need both the base game Terraria for $9.99 and TmodLoader for free both availible on the Steam application.
Due to some complications with the way I implemented things, the mod is untested in multiplayer and so I have not posted it to the Steam Workshop yet.
To run this mod:
- Download and unzip this zip file: [TutorialMod.zip](https://github.com/user-attachments/files/27251572/TutorialMod.zip)
- Locate the file called 'Tutorial Mod'
- Now locate the 'ModSources' folder
  - Typically found in Documents\My Games\Terraria\tModLoader
- Drag this folder into the 'ModSources' folder
- Now open up tModLoader
- Click 'Workshop'
- The mod should be there, now click 'Build + Reload'
- Now click 'Back' and go to 'Manage Mods' and enable it if it is not already

To be able to change or modify the code of this mod you must have a text editor compatible with C#, I used Visual Studio for free.
- Either clone this repo or click the small folder icon in the 'Workshop' section then locate the TutorialMod.csproj to start coding
